## 🔐 PRIVACY & SECURITY

### Your Wallet Addresses Are Protected

**Public Receipts** (what anyone can see):
```json
{
  "receipt_id": "RCP_260403085620_652620ff",
  "amount_usd": 25.00,
  "wallet_reference": "1yQdHk...z4v2",  // MASKED
  "wallet_hash": "6985f982ba859768",
  "source": "affiliate_conversion"
}
```

**Private Receipts** (only you can see):
```json
{
  "wallet_address": "1yQdHkfK3FRh2ChqMGdWcrxjqhtqbz4v2",  // FULL
  "wallet_masked": "1yQdHk...z4v2"
}
```

### Security Features

- ✅ **File Permissions**: Private files are owner-only (600)
- ✅ **No Secrets in Code**: Wallets in environment variables
- ✅ **Integrity Hashes**: Every receipt has tamper-evident hash
- ✅ **Masked in Logs**: Full addresses never appear in shared logs
- ✅ **You Control Keys**: RM-QPT never has your private keys

### What RM-QPT CANNOT Do

❌ Withdraw money from your wallets  
❌ Access your Coinbase account  
❌ See your private keys  
❌ Spend your crypto  

**RM-QPT can only:** Send money TO your wallets (deposits)

## 🛠️ TROUBLESHOOTING

### System Won't Start

```bash

ps aux | grep rm-qpt

# Kill old processes if needed
kill $(cat state/execution_24h.pid)

# Restart
bash EXECUTE_24H_AUTONOMOUS.sh
```

### No Money Coming In

```bash
# Check logs
tail -f logs/*.log

# Verify wallets configured
python3 core/crypto_integration.py

# Check if stream is running
ps aux | grep money_stream
```

### Can't See Receipts

```bash
# Check directory exists
ls -la receipts/
```
