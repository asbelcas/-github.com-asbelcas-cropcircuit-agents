CropCircuit · Open Farm Utilities

Useful farm infrastructure before a sales pitch.

Free, local-first calculators, labor tools, funding data, reusable code, and privacy-preserving benchmark infrastructure for small farms and the people who support them.

Design rule: the tools should solve a real problem even if nobody pays. Most standalone tools run entirely in your browser and do not require an account.

Offline-first by design

Once served from a secure static host, the landing page can cache core tools for repeat offline use while keeping time-sensitive funding data network-first.

Offline web-app policy

Static calculators and local tools cache for resilience; funding data prefers the network so deadlines do not silently freeze.
