# Contributing to CropCircuit Open Farm Utilities

Useful corrections and additions are welcome.

## Funding opportunity submissions

A funding record should be based on a **primary source** whenever possible: the administering government agency, university, foundation, or program owner.

A proposed record should include:

- program title
- provider
- primary-source URL
- current status: open, continuous, watch, paused, or closed
- deadline and timezone when one exists
- funding amount or funding mechanism when stated by the source
- intended audience
- Michigan county restrictions, if any
- a short neutral summary
- verification date

Do not submit scraped grant-directory summaries as the sole evidence for an opportunity.

## Corrections matter as much as additions

Please flag:

- an "open" program whose deadline passed
- changed award amounts
- a new deadline
- a paused/cancelled program
- county eligibility changes
- broken primary-source links
- an opportunity that was duplicated

## Code contributions

Public utility code should:

- avoid unnecessary dependencies
- keep assumptions explicit
- include a small test when practical
- avoid analytics, tracking, or hidden network calls
- work without requiring a CropCircuit account

The goal is durable utility, not lock-in.
