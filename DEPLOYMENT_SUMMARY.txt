═══════════════════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

PHASE 1: AUTONOMOUS (Level 4)
├── System monitors for opportunities 24/7
├── System filters by criteria (budget, skills, timeline)
├── System drafts proposals using templates
└── System creates checkpoint (pauses)

PHASE 2: CHECKPOINT (Level 3)
├── System presents: "Proposal ready - review?"
├── Shows: Full proposal + opportunity details
├── You spend: 5 seconds to review
├── You choose: approve / edit / reject / pause
└── System waits for your response

PHASE 3: APPROVED (Returns to Level 4)
├── System submits proposal
├── System monitors for client responses
├── System drafts response to client
├── System creates checkpoint (pauses)
└── Loop continues
