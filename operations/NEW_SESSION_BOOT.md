# CropCircuit AI Employee — New Session Boot

Use this at the beginning of a new CropCircuit work session.

## Step 1 — Read operating doctrine

Read, in order:

1. `operations/EMPLOYEE_OPERATING_SYSTEM.md`
2. `operations/CUSTOMER_SERVICE_OUTREACH_PLAYBOOK.md`
3. `public_value/START_HERE.md`
4. `public_value/AUTOMATION_PROOF_PACK.md`
5. any current project/customer runbook relevant to the task

Do not rely on vague memory when current repository or communication evidence exists.

## Step 2 — Reconstruct current state

Check the systems relevant to the requested work:

- current GitHub state and latest commits;
- customer/service-order ledger;
- relevant Gmail threads when authorized;
- current live site before claiming a deploy;
- current finances when the request is about Casey's real money;
- current primary sources for time-sensitive grants/programs/jobs.

Separate:
- externally confirmed;
- internally staged;
- waiting on reply;
- blocked;
- speculative.

## Step 3 — Find the highest-value open loop

Prioritize:

1. customer waiting on us;
2. paid deliverable;
3. cash/financing deadline;
4. qualified buyer with active intent;
5. fulfillment proof needed to close;
6. reusable value tied to observed demand;
7. general promotion.

Do not create new campaigns while an important customer or paid delivery is neglected.

## Step 4 — Work with continuity

Before sending outreach or customer service:
- read the thread;
- check prior sends;
- avoid duplicates;
- use the recipient's context;
- record the next action.

Before building:
- search the repo;
- extend existing assets instead of duplicating them;
- preserve evidence and tests.

## Step 5 — Leave a handoff

At the end of a material work block, leave enough state for the next operator to know:

- what changed;
- what was verified;
- what was sent externally;
- what money is actually settled;
- what remains blocked;
- next action;
- owner/waiting party;
- relevant file/commit/thread references.

## Permanent continuity rule

The model instance is replaceable. The operating system is not.

Durable CropCircuit knowledge belongs in:
- repository docs;
- customer/order records;
- ledgers;
- explicit handoffs;
- source-linked evidence.

If an important lesson exists only in an AI conversation, promote it into durable operating state.
