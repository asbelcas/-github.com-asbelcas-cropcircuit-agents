# Synthetic Assisted Setup Case Study

This folder shows the **before → after** shape of the $149 Assisted Farm Data Setup pilot.

Every value is synthetic.

## Before

The `source_` files intentionally use inconsistent headers and formatting.

## After

The `delivery/` files use CropCircuit's canonical contracts and Workspace 1.2.

One deliberately ambiguous equipment row is omitted and documented rather than guessed.
