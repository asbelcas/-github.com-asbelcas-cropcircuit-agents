Equipment Cost Threshold Analyzer

Start with measured annual labor cost, choose a realistic time reduction and payback horizon, and calculate the maximum upfront cost that would fit that target.

This is a threshold, not a recommendation. It answers “what purchase price would fit my assumptions?” It does not claim that a particular machine, layout change, or automation will actually save the assumed time.
Value gate comes first when needed. If the intervention touches animal welfare, soil/water, human capacity, safety, or resilience, run the Right Relationship Decision Gate before treating the financial threshold as actionable. A hard constraint is not erased by a better payback.
